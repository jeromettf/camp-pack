# 🏕️ 우리 가족 캠핑 준비 — 설치 가이드 (처음 한 번, 약 10분)

준비물은 모두 갖춰져 있습니다.

| 구성 | 위치 | 상태 |
|---|---|---|
| 데이터 시트 | 구글 드라이브 **「캠핑 준비 (camp-pack)」** | ✅ 생성됨 (기본 준비물 132개 포함) |
| 앱 화면 | https://jeromettf.github.io/camp-pack/ | ✅ 배포됨 |
| 서버 코드 | https://github.com/jeromettf/camp-pack/blob/main/apps-script/Code.gs | 👉 시트에 붙여넣기 필요 |

> PC에서 진행하는 것을 권장합니다.

---

## 1단계. 시트에 코드 붙여넣기 (3분)

1. 구글 드라이브에서 **「캠핑 준비 (camp-pack)」** 시트를 엽니다.
2. 상단 메뉴 **[확장 프로그램] → [Apps Script]** 를 누릅니다. 새 탭이 열립니다.
3. 왼쪽 `Code.gs` 파일 안의 기존 내용(`function myFunction() {…}`)을 **모두 지웁니다**.
4. 아래 주소를 열고, 오른쪽 위 **복사 아이콘(Copy raw file)** 으로 전체 코드를 복사해 붙여넣습니다.
   https://github.com/jeromettf/camp-pack/blob/main/apps-script/Code.gs
5. **💾 저장** (Ctrl/Cmd + S). 프로젝트 이름을 물으면 `camp-pack` 으로 입력합니다.

## 2단계. 초기 설정 실행 (2분)

1. Apps Script 편집기 위쪽 함수 선택 상자에서 **`setup`** 을 고르고 **▶ 실행** 을 누릅니다.
2. **권한 검토** 창이 뜨면:
   - 본인 구글 계정 선택
   - "Google에서 확인하지 않은 앱" 화면 → **[고급] → [camp-pack(으)로 이동(안전하지 않음)]**
     (본인이 만든 스크립트라서 나오는 정상 경고입니다)
   - **[허용]**
3. 시트로 돌아가면 "✅ 초기 설정 완료" 창이 뜨고, 탭이 9개로 늘어나 있습니다.
   (준비물 · 수납함 · 장소 · 구성원 · 캠핑 · 체크 · 회고 · 설정 · 변경이력)

## 3단계. 웹 앱 배포 (2분)

1. Apps Script 편집기 오른쪽 위 **[배포] → [새 배포]**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정:
   - 설명: `camp-pack`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **[배포]** → 표시되는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`) 을 복사합니다.

> "모든 사용자"여도 **가족 코드가 없으면 데이터에 접근할 수 없습니다.**

## 4단계. 휴대폰 연결 (1분)

1. 시트를 새로고침하면 상단에 **🏕️ 캠핑 준비** 메뉴가 생깁니다.
2. **[🏕️ 캠핑 준비] → [2. 가족 초대 링크 보기]** → 3단계에서 복사한 URL을 붙여넣고 확인
3. 나오는 **초대 링크**를 카톡 "나와의 채팅" 등으로 휴대폰에 보내고 엽니다.
4. "누구세요?" 화면에서 이름(예: 아빠)을 등록하면 끝!
5. **홈 화면에 추가** 하면 앱처럼 쓸 수 있고, 캠핑장에서 인터넷이 없어도 열립니다.
   - iPhone(Safari): 공유 버튼 → **홈 화면에 추가**
   - Android(Chrome): ⋮ 메뉴 → **홈 화면에 추가** (또는 "앱 설치")

---

## 가족 추가하기 (언제든지)

1. 앱 **[설정] → [가족 구성원] → [+ 구성원 추가]** — 이름, 구분(어른/아이/영유아/반려견), 알림 받을 이메일(선택)
2. **[설정] → [📤 초대 링크 보내기]** 로 가족에게 링크 전송
3. 가족은 링크를 열고 "누구세요?"에서 자기 이름을 고르면 끝
   - 아이·반려견처럼 앱을 쓰지 않는 구성원도 등록해 두면 인원 계산에 반영됩니다.
   - 구글 계정이 없어도 사용할 수 있습니다.

## 자주 쓰는 관리 기능

| 하고 싶은 것 | 방법 |
|---|---|
| 준비물 한꺼번에 정리 | 시트 `준비물` 탭에서 직접 수정 (드롭다운 제공). 앱은 자동으로 반영 |
| 오타 확인 | 앱 홈/창고에 **⚠️ 규칙 오류** 가 뜨면 눌러서 수정 |
| 링크가 유출됨 | 시트 메뉴 **[가족 코드 재발급]** → 새 초대 링크를 가족에게 다시 전송 |
| 알림 메일 끄기 | 앱 [설정] → 알림 |
| 수납함 바꾸기 | 앱 [창고] → [수납함] |

## 코드 업데이트가 필요할 때 (드물게)

- **앱 화면**은 자동으로 최신 버전이 적용됩니다 (할 일 없음).
- **Code.gs** 를 바꿔야 할 때만: 코드 붙여넣기 → 저장 → **[배포] → [배포 관리] → ✏️ 편집 → 버전: "새 버전" → [배포]**
  ⚠️ "새 배포"를 다시 만들면 주소가 바뀌어 가족 링크가 끊깁니다. 반드시 **기존 배포를 편집**하세요.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 앱에 "⚠️ 연결 끊김" | 가족 코드가 바뀌었음 → 새 초대 링크로 다시 열기 |
| 앱에 "오프라인 · 대기 n" | 정상입니다. 인터넷이 연결되면 자동 전송됩니다 |
| 날씨가 안 나와요 | 앱 [창고] → [장소] 에서 해당 장소의 **위치 찾기** 로 위치 지정 |
| 메뉴가 안 보여요 | 시트 새로고침. 그래도 없으면 Apps Script에서 `onOpen` 실행 |
